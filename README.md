DealRadar — a Black Friday / Cyber Monday deal finder with 32 real deals, checked by hand on 27 November 2026 from store pages and named deal sources. Every deal shows its product, store, store link, sale price, usual price, discount, when the price was checked, where it was read, and an honest verdict on whether it is really a deal. Search and filter by category, store and discount; sort by biggest saving, biggest percent or lowest price; open any deal for its full evidence.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — the site is plain static files under `app/` and makes no network request of its own.
